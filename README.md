## 🚀 Geopublica 2019 Project

The Geopublica 2019 project is a sophisticated demonstration of modern API development using GraphQL and Flask. It serves as both a learning resource and a practical example of implementing GraphQL in a Python environment.

### Key Features

- GraphQL API implementation using Flask and Graphene
- Comprehensive type system
- Schema language examples
- API implementation examples
- Documentation and study materials

### Technology Stack

- **Backend Framework**: Flask 1.0.3
- **API**: GraphQL (Graphene 2.1.5)
- **Database**: PostgreSQL (psycopg2)
- **Data Processing**: Pandas, NumPy
- **Development Tools**: Black, Flake8

### Project Structure

```
geopublica-2019/
├── 01-types/         # Type system examples
├── 02-schema_language/ # GraphQL schema examples
├── 03-others/        # Additional examples
├── 04-api/           # API implementation
├── docs/             # Documentation
├── env.sh            # Environment setup
├── geopublica.yml    # Conda environment
└── requirements.txt  # Python dependencies
```

## 🛠️ Getting Started

### Prerequisites

- Python 3.6+
- Conda (recommended) or pip
- PostgreSQL

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/patricksferraz/public-presentation.git
   cd public-presentation
   ```

2. Set up the environment:
   ```bash
   cd geopublica-2019
   source env.sh
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
